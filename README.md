# Pullman Cultural Trail: Version History

Archived snapshots of the Pullman Cultural Trail app, preserved to show how it developed during 2026.

- `index.html`: landing page with a timeline of versions
- `2026-04-24/`: first complete version (21 stops)
- `2026-06-22/`: last version before thematic routes
- The current app lives at [mcmahonag/pullman-cultural-trail](https://github.com/mcmahonag/pullman-cultural-trail)

Snapshots are copied from the main repo's history (commits `438dcc3` and `99e0679`). Two changes: the CARTO map tile API key from the current app (CARTO now requires one for the map to load), a strip linking back to the version list, and the iOS 26 status-bar fix (header extends behind the clock; content clears the edge blur and the home-swipe bar).
